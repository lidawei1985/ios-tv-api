# ios-tv-api — IOS3APP 自有电视剧公网 API

**架构铁律（用户钦定 2026-09-20）**：第三方 CMS 资源站只是原料，必须经本引擎采集→过滤→归一后
以自有 API 发布；App 端只认自家 API，逐步切断第三方直连。

## ⚠️ 内容红线：本仓库永久零成人内容
- 只收录星幕（家庭档）电视剧；采集时三道过滤闸：
  1. 分类级：只放行正统剧类（含「剧」且不以「片」结尾，排除漫剧；封杀伦理/情色/体育/综艺等）
  2. 条目级：标题/分类命中违禁词黑名单即剔除；无播放数据的死条目源头剔除
  3. 发布机检：发布前扫描全部产出物，命中违禁词**中止发布**（audit gate）
- **成人内容（夜航）永远不得进入本仓**；如需自有 API，一律私有仓+鉴权通道。

## API 契约（App 端 OwnTVClient 消费）
- `GET /data/catalog.json` → `{"updated", "sources", "categories":[{"id":"c1","name","count"}]}`
- `GET /data/{cid}.json` → `{"cat", "items":[{"id":"liangzi:123","t":标题,"y":年份,"pic":海报,"from","pu":播放串,"cat","src"}]}`
  - 全量条目自带播放数据，App 自行分页（60/页）与客户端搜索；年份新→旧预排序

## 无人值守
GitHub Actions 每 6 小时自动采集刷新（`tools/collect.py`，纯标准库零依赖）。
